- 按压/悬停反馈约 160–180ms；信号划入约 700ms，手掌/爱心仅执行一次短动效；收到回应展示 4.5 秒。
- 发送与收到使用相反划入方向，收到内容不会覆盖或遮挡播放控制。
- 提供静态效果按钮，尊重 `prefers-reduced-motion`；减少动态时保留明确文字与静态图形。
- 装饰图形对辅助技术隐藏，操作按钮有文字和键盘焦点，发送反馈使用状态提示，不自动播放提示音。
- 模拟交换页加入选歌、发送中的点状提示和结果卡动效，仍保留模拟声明，不将其称作双人真实交换。

## 双端协议

1. 已加入且双方在线时，任一角色可发送 wave / heart；服务端从已认证的连接确定发送身份，不信任客户端自报角色。
2. 请求带 UUID、曲目和估计服务端时间；拒绝过期、错误曲目或对方离线的回应。
3. 服务端接受后返回“已发出”，对方客户端接到事件并回执后才向发送端返回“已送达”。送达表示客户端确认，不能等同于对方已读。
4. 客户端及服务端均按每人 2 秒一次节流；近期事件按 UUID 去重。重发同 ID 不再次投递或播放动效。
5. 有效期 6 秒；超时显示未确认送达，不自动排队补发。迟到回执不把过期事件变为送达。
6. 回应不改变播放版本、曲目或进度，不写入收藏或音乐足迹。只保留会话内有限的去重数据，关闭会话时一并清理。
7. 重连快照不携带旧表情，不重播离线期间的动效；退出、切号和授权失效沿用既有会话权限及清理规则。

## 验证

- 协议用例验证固定表情、ID、时间及曲目格式，并丢弃伪造发送角色字段。
- 两项真实服务集成测试覆盖双向发送、收件回执、自己不能确认自己送达、幂等、节流、过期、换曲、离线、无身份发送、重连不重放以及迟到回执。
- 浏览器独立模拟 A/B 身份互发招呼/爱心，收件端出现对应文字，发送端在回执后显示已送达；结束会话后按钮禁用。
- 375px 实际页面无横向溢出，素材已目视检查；点击静态效果后计算样式为 `animation-name: none`。系统级减少动态设置有 CSS 支持，本轮未切换系统设置。
- 类型检查、lint、生产构建通过；共 28 项测试通过（单人 8、同步协议 8、同步服务 1、附近服务 6、账号服务 3、表情服务 2）。本轮没有实现真实交换、聊天、好友或官方 QQ 接入。
