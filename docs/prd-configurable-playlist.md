# 同频 v0.8：可替换模拟歌单

范围：QQ 音乐内嵌概念原型继续使用模拟宿主和演示区域；歌曲由项目所有者自行放入本地目录。双端邀请、播放、表情及换歌保持真实客户端交互，不依赖官方 SDK。

## 本轮实现

- `config/playlist.json` 统一配置稳定 ID、歌名、歌手、音频路径、可选封面/颜色/来源备注。
- 启动和构建前解析本地音频，生成客户端/服务端共享清单，包含真实时长、MIME、大小和内容版本。
- 雷达按当前歌单派生模拟听众；歌曲多于四首时可通过刷新轮换。交换、宿主选曲、播放器与收藏使用相同曲库。
- 所有业务播放时长改由音频/清单决定，不再使用固定 24 秒。仍沿用有限大小的完整缓冲，适合少量本地模拟歌曲。
- 自备封面贯穿歌卡、匹配详情、试听、交换与足迹；失败时回退默认图形。
- 歌曲下架保留账号记录和清单中的最后资料，禁止播放但允许取消收藏/移出待听；恢复同一 ID 可继续使用原收藏。
- 空歌单可查看旧记录；单首歌禁用交换；更新歌单后结束旧版本会话，旧页面提示刷新，已完成交换的补存不因歌曲下架被拒绝。

操作说明见 [替换模拟歌单](./playlist-guide.md)。不新增上传后台、远端曲库、QQ 授权或真实定位。

- 浏览器实际播放 MP3，读取时长 2.088 秒，封面加载成功；35.25 秒音频实际拖动到 35 秒以后。
- 本地会话服务接受 30 秒进度，并按 35.25 秒限制终点，确认超过旧 24 秒长度后仍可同步。
- 移除测试歌后，旧收藏/足迹保留名称且不可播放，取消收藏成功；单首禁用交换，空歌单不崩溃且旧记录仍可查看。
- 测试用临时歌单与素材已恢复/清理，默认仍为原来的四首试听。
