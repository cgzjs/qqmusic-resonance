# 同频 PRD v0.4：附近相遇与在线邀请

> 历史版本记录。身份约定见 [v0.5](./prd-host-integration.md)，当前入口、存储和后续计划以 [v0.6.1](./prd-integrated-experience.md) 为准。附近邀请规则继续沿用；手选歌曲向导已移入模拟宿主调试面板，原单人入口已合并。

日期：2026-09-20。替代 v0.3 的链接邀请入口，同步播放底层保留。本轮仅本地实现，不公开部署。

## 产品定位

和附近的陌生人，因为音乐产生一次相遇。车站、校园、咖啡店只是场景，不限制同车厢，不以好友分享链接作为主流程。

主流程：主动开启附近发现 → 看见另一位听众分享的歌曲 → 发出同频邀请 → 对方接受 → 两人一起听 → 任意一方结束。

## 本轮范围与真实程度

- `/nearby` 为封面主入口。单人模拟音乐体验保留在 `/experience`，清楚标注模拟数据。
- 本轮使用一个固定且明确标注的演示区域：其中的听众、邀请、接受与同步都来自真实客户端；区域不代表实际地理距离。不开启定位、蓝牙、账号或 QQ 音乐接口。
- 用户选一首内置合成试听并主动开启发现，展示服务器生成的匿名代号和所选歌曲。文案为“正在分享”，不冒充读取音乐软件当前播放。
- 不注入虚拟在线听众或自动接受。没有其他客户端时展示空态与双标签页测试提示。
- 开启后才能发现与被邀请；暂停即删除在线身份并撤回待处理邀请；关闭页面尽力即时退出，异常断网最多 30 秒后退出。
- 接受后两人立即从发现列表隐藏。返回发现页需要再次主动开启。

## 邀请状态与规则

| 状态 | 发起方 | 接收方 |
| --- | --- | --- |
| 待回应 | 查看歌曲与等待状态、撤回 | 接受、暂时不了、忽略 |
| 已接受 | 进入同步会话 | 进入同步会话 |
| 已婉拒 | 显示暂未同频 | 返回发现 |
| 已撤回 | 返回发现 | 显示邀请撤回 |
| 已到期 | 显示超时或离线 | 旧邀请不可接受 |

- 邀请有效期 45 秒，服务器判定超时；任一方离线也失效。页面倒计时随 2.5 秒心跳更新。
- 每人最多一份待处理邀请；每 15 秒最多发一次，同一对听众 60 秒冷却。演示区域最多 100 个在线身份。
- 接受/拒绝只能由接收方执行；撤回只能由发起方执行；客户端不能自报另一人的身份。并发接受只创建一个会话，重复操作返回失效。
- 双方接受时才分配同步会话：被选中歌曲的一方控制播放，邀请方跟听；音量独立。初始暂停，用户点击加入，浏览器要求时点击开启声音。
- 任意一方主动结束即关闭整次同频。断线暂停、重连保留席位 90 秒、最长 2 小时，沿用已有同步协议。

## 数据与实现

- `NearbyArea` Durable Object 保存匿名在线身份及邀请，区域内串行处理接受操作；5 秒清理任务。到期身份删除，邀请在截止时间 2 分钟后删除。
- `POST /api/nearby/start`：选择合法曲目，生成服务器身份和不可猜测会话凭据。其余接口通过 Authorization 验证身份。
- `GET /api/nearby/state`：更新心跳，返回公开听众、自己的邀请、仅自己的同步凭据。
- `POST /api/nearby/invite`、`respond`、`stop`：邀请、回应、停止发现。JSON 上限 1024 字节，校验请求来源。
- 接受后的凭据只写入本标签页 sessionStorage；URL 不带邀请链接；附近同步会话不向带领者下发另一人的凭据。
- `/room` 旧入口重定向 `/nearby`；`/room/:id` 仅承载双方已同意的内部播放会话。旧创建 API 仅保留本地同步回归测试用途，界面没有创建和分享链接入口。
- 本轮不新增聊天、好友关系、精准距离、真实双人换歌。原单人换歌页仍为模拟。

## 验收清单

- 两个标签页开启发现后可互相发现，未开启的页面不出现在列表。
- A 邀请 B；B 接受前没有同步会话凭据；C 不能接受或撤回该邀请。
- 婉拒、撤回、45 秒超时、暂停发现、重复接受、冷却均有服务验证。
- B 接受后仅两人获得各自权限的同一会话凭据，曲目是 B 分享的歌；第三人不能获取凭据。
- 双端加入可实际播放、暂停；任一方结束使另一端停止。
- 桌面、375px 页面无横向溢出；错误、空态、等待态清晰；键盘可操作。
- 原单人和同步协议回归、附近服务集成测试、类型检查、lint、构建。

## 后续边界

真实附近需要另行确定区域划分、位置授权与精度；当前演示区域不可用作真实地理匹配。匿名原型的冷却不能防止重新创建身份绕过，公开发布前需要服务侧限流及举报/屏蔽能力。跨设备、公网、iOS 与长时间后台尚未验收。保留 v0.3 已记录的 Vinext beta 预取和 Wrangler 本地代理限制。

## 本轮验证记录

- 8 项单人测试、7 项同步协议测试、1 项同步服务测试通过；新增 4 项附近服务测试通过，共 20 项。附近测试还在独立 Miniflare/workerd 的生产构建中通过，包括实际等待 45 秒超时、身份离线、并发接受、越权、冷却、暂停撤回、来源及体积限制。
- TypeScript、ESLint、生产构建通过；生成配置包含 `NEARBY` 绑定与对应 SQLite 类迁移。
- 开发和生产浏览器双端走通：主动发现、邀请、接受、进入同一会话。生产两端实际 audio 播放《晚风慢拍》，一次稳定采样为 13.996s / 14.067s；暂停后两端均 paused，位置为 23.003s / 23.050s。仅为本机采样，不代表公网保证。
- 跟听方点击返回附近后，分享方收到会话结束，公共操作禁用；两端均可返回发现且不自动重新公开身份。
- 375px 邀请卡已截图检查，接受和婉拒按钮可操作；页面没有横向滚动。旧 `/room` 地址已验证跳转 `/nearby`。
- 公网、真实地理定位、跨设备及 iOS 没有验收。v0.3 的框架/预览代理问题不在本轮宣称修复范围。
