# 同频产品说明

最新歌单能力见 [v0.8 可替换模拟歌单](./prd-configurable-playlist.md) 与 [换歌操作说明](./playlist-guide.md)。当前按 QQ 音乐内嵌概念原型继续推进，官方接入尚未取得，不作为这一阶段的开发前提。

当前体验依据：[PRD v0.6.1](./prd-integrated-experience.md)；v0.7 的 [双端轻回应](./prd-reactions.md) 和 [真实双人交换](./prd-live-exchanges.md) 均已完成本地实现与验证。

## 定位与原则

同频是 QQ 音乐内嵌功能插件，复用宿主账号与当前歌曲，不独立注册。目标是让附近的陌生人因为音乐产生低压力的短暂相遇，车站、校园、咖啡店只是场景，不限定同车厢。

1. 音乐先于身份，对外显示匿名代号和音乐。
2. 登录不等于开启发现，公开音乐由用户主动选择。
3. 邀请被接受后才建立双人共听；用户随时可退出。
4. 附近只表达粗粒度区域，不展示精确位置。
5. 保留原有雷达、详情、跟听、交换和足迹，新增服务接入这些流程，不另做缩水首页。
6. 模拟与真实客户端交互明确区分，不把演示区域或宿主模拟当成真实 QQ 接入。

## 入口与功能

| 入口/状态 | 内容 | 当前程度 |
| --- | --- | --- |
| `/` | 封面及进入同频 | 已完成 |
| `/nearby` → 场景体验 | 雷达、场景、匹配详情、试听、表情、交换 | 音频真实播放；听众、相似度及互动回应为模拟 |
| `/nearby` → 在线听众 | 主动发现、真实客户端邀请、接受/拒绝/撤回/超时 | 已完成，区域不代表实际地理距离 |
| `/room/:id` | 双端播放、表情、互相选歌交换、退出/重连 | 已完成，使用内置合成试听；交换有独立回应与账号记录 |
| 足迹与收藏 | 模拟事件、在线同频历史、收藏与待听、播放及移除 | 当前账号服务端保存，区分记录来源 |
| `/experience`、`/room` | 旧地址兼容 | 重定向到统一首页 |

内部切换保留播放器与在线邀请提示；进入真实会话停止旧试听。切号、退出或授权失效清理界面及播放。空列表、刷新和暂停状态隐藏雷达中心图标，避免遮挡提示文字。

## 数据与接入边界

- 曲库配置在 `config/playlist.json`，准备脚本读取真实音频信息并生成共享清单；场景样本仍在 `lib/resonance/demo-data.ts`。默认保留四段原创合成试听，可自行替换歌单。
- 收藏、待听、最多 300 条场景事件及最多 100 条在线收听记录按模拟宿主账号持久化。刷新/重新授权后可恢复，不同账号隔离。
- 旧浏览器匿名本地缓存不自动归入任意宿主账号；数据仍保留，不冒充 QQ 收藏同步。
- 当前只有本地模拟宿主 A/B 和应用自有适配契约，没有接入官方 QQ SDK、真实授权、真实地理位置或正式曲库。
- 生产默认关闭模拟宿主，当前未公网部署。
