# 同频产品说明

## 产品目标

让用户在地铁、校园和咖啡店等真实空间中，通过正在播放的音乐产生低压力、短时、匿名的连接。

## 产品原则

1. 音乐先于身份：页面首先展示歌曲，不展示真人资料。
2. 粗粒度位置：只表达同一车厢、附近区域或刚刚擦肩。
3. 轻互动：第一版只提供跟听、表情回应、推荐和收藏。
4. 双方同意：没有共同回应时，不提供追踪或再次联系。
5. 可退出：用户可以随时暂停被发现。

## 页面状态

| 状态 | 用户目标 | 主要动作 |
| --- | --- | --- |
| radar | 浏览附近音乐 | 选择歌曲、暂停发现、切换模拟场景 |
| match | 判断是否愿意靠近 | 跟听、直接推荐歌曲 |
| listening | 共享短暂听歌时刻 | 打招呼、喜欢、交换一首 |
| exchange | 互相推荐歌曲 | 选择歌曲、发送、收藏回应 |
| journey | 回顾当天音乐旅程 | 查看统计、返回雷达 |

## 原型数据

当前数据保存在 `lib/resonance/demo-data.ts`。它只用于演示 UI 与交互，不代表真实用户、实时位置或 QQ 音乐接口返回值。

## 未来接入点

- 音乐服务：歌曲 ID、授权试听地址、播放进度
- 附近发现：区域级服务端判断与主动开启的蓝牙近场能力
- 同步服务：房间状态、播放偏差校准、互动事件
- 隐私控制：发现时段、区域屏蔽、举报与安全策略

这些能力不在当前 MVP 内。
